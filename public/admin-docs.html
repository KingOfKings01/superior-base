Superior Base Admin - Quick Guide

Welcome to the Superior Base Admin! This short guide will help you manage your database quickly and easily.

1. Accessing the Superior Base Admin

You can access the admin dashboard by navigating to /admin in your browser. You will need to log in using an administrator account (which you can create via the npm run createsuperuser script).

2. Managing Tables (Collections)

  • View Tables: The sidebar lists all existing tables in your database.
  • Create Table: Click the "+ New Table" button in the sidebar. You can define custom columns (Text, Number, Boolean, or Relations).
  • Edit Schema: Click the gear icon (⚙️) next to a table to add new columns to an existing table.
  • Delete Table: Click the trash icon (🗑️) to drop a table entirely. Warning: This deletes all data in the table!

3. Managing Data (Records)

  • View Records: Click on any table in the sidebar to view its data in a spreadsheet-like grid.
  • Add Record: Click "Add Record" at the top right to insert a new row.
  • Edit Record: Click the "Edit" button on any row to modify its contents.
  • Delete Record: Click the "Delete" button on a row to remove it permanently.

4. User Management

The User table is built-in. You can view registered users, edit their roles, or delete users directly from the grid just like any other table.

Pro Tip: When setting up a table relation, ensure the parent table already exists!
